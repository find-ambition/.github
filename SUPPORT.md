# Support

Use the repository issue forms for reproducible bugs and scoped feature requests.
Before opening an issue, check the existing issues and the project's roadmap for duplicates.

Email `support@findambition.com` for security concerns or other matters that should
not be public. For Tanikala account access, privacy requests and safety reports,
email `support@tanikala.ph`. Never place passwords,
tokens, government identifiers, payment details, private reviewer content, or another
person's personal data in a GitHub issue.
